## 2. “穿上没有助力”能下什么结论

当前只能给出代码层面的原因清单，不能远程断言是哪一项：

1. 板上可能是 `imu_only`、只读 `motor_test` 或其他旧构建。这些模式本来就不执行正常助力控制。
2. 重力补偿默认参数全为 0；小顺势助力分量默认上限仅 0.35 Nm，低速还受死区限制。
3. FSM 可能停留在 `SAFE`，或者状态控制被命令关闭，或者机械软限位在阻止朝边界输出。
4. 编码器/IMU 安装、方向、CAN ID、波特率、穿戴零位或 NVS 参数可能与历史配置不符。
5. 已计算出的力矩未必被电机有效执行：需要比较 `tau_cmd`、`tau_fb`、反馈新鲜度、故障和实际运动，而不是只看上位机能连上。

尤其注意：当前 `transparent` 仍包含状态阻抗/重力通道，`SAFE` 仍可能有输出；两者的名称不能作为“零输出/已停机”的证据。详细控制链见 [架构说明](architecture.md#5-状态机与实际力矩计算)，恢复与烧录步骤见 [README](../README.md)。

## 4. P1：让控制与实验可复现

### 标定与模式一致性

- **明确零位优先级。** 当前启动平均得到的 `user_zero` 可能被之后加载的 NVS `motor_zero` 覆盖。应区分机械标定、当次穿戴标定和历史参数；用带版本、校验和、装配标识的结构保存，并报告来源。
- **统一模式入口。** `wear/transparent`、`SAFE`、`STATE_CTRL`、`GRAV_ENABLE`、手动控制是不同维度；应在固件身份和遥测中明确哪些分量处于激活状态，避免靠按钮名称推测。
- **清理无效配置。** `KNEEEXO_GAIT_IMU_ENABLE` 目前不控制 FSM 执行；`DEFAULT_KP/KD` 不控制 normal 的 MCU 阻抗公式。为配置增加清晰用途或移除失效项。
- **统一小腿通道。** 定义了 `SHANK_IMU_UART_NUM`，但 normal 中仍直接使用 `IMU2_UART_NUM`；使用语义通道常量贯穿初始化、控制和遥测。
- **统一符号定义。** 重力函数实际返回并累加 `G*sin(theta+phi)+bias`；旧注释曾写负号。需要用已知方向的离体静态工况确认“补偿力矩”定义，并将该约定用于固件、拟合和文档。

### 时间、数据与并发

- 为 IMU 欧拉角、陀螺仪和加速度分别记录样本时间，区分收到新样本与重复读取缓存。目前用欧拉角差分和控制环滤波，容易受低采样率、不同帧到达顺序影响。
- 9600 bps、8N1 每秒约传 960 字节；加速度/角速度/欧拉角三帧共 33 字节，理论完整组速率不到 30 Hz。因此 100 Hz 控制读取不等于 100 Hz 新 IMU 数据。
- 给电机最新反馈快照加一致性保护；命令任务通过队列或双缓冲提交整组参数，避免控制任务读到部分更新的结构。
- 将打印、ADC 和慢操作从控制任务分离。测量周期时间、jitter、CAN 延迟、丢帧、队列长度和最坏执行时间，再评价 PRD 的 `<5 ms` 或 `±200 μs` 目标。
- 遥测增加协议版本、序号和传感器原始时间；记录固件身份、有效配置、NVS 参数和上位机版本。实时显示可以丢积压，但实验记录应单独保留丢帧统计。

### 用数据验证控制

先完成零指令/被动阻尼、重力补偿、单个 FSM 状态的离体验证，再验证状态切换。每次实验至少记录：装配与方向、命令来源、零位、完整参数、原始 CSV、场景、异常与判据。

[transparency_report.py](../tools/transparency_report.py) 的力矩 RMS 和速度相关性只能描述电机反馈数据；它们不能单独证明人体关节受力、肌肉负担降低或步行代谢改善。状态识别验证也需要视频、接触传感器或人工标注等独立参考，不能用算法自己输出的状态当作真值。

## 6. 建议的恢复里程碑

1. **确认身份与接线**：保存板上启动日志、构建 profile、串口、CAN ID、两路 IMU 接线和零位；明确现场实际硬件与仓库配置的差异。
2. **恢复只读链路**：分别验证 IMU 数据和电机机械位置反馈；不能以 TWAI 自环成功替代真实电机通信测试。
3. **完成 P0 闭环**：先验证故障/超时/限位/停止，再开放有源实验。
4. **验证单个力矩来源**：逐项确认零输出、阻尼、重力与手动小力矩的符号和响应，记录命令/反馈。
5. **验证状态机**：在独立参考标注下回放与离体测试，检查错误转移和超时。
6. **再评价穿戴助力**：在上述条件满足后另行制定穿戴实验和效果判据，逐步决定参数，而非直接把电机额定/峰值力矩当作助力设定值。

重新烧录只改变 MCU 程序，不能自动修正机械装配、RS02 CAN ID、IMU 配置或已有 NVS 参数，也不能替代这些验收步骤。
