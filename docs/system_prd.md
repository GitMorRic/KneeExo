# KneeExo 产品需求文档 (PRD)

> 本文保留最初的产品需求与性能目标，不代表当前全部已实现或已验证。当前实现、接线和限制请以[项目现状](project-status.md)、[架构](architecture.md)、[规格](specs.md)为准。可靠停机、欠压/过温策略、双腿和康复轨迹尚未形成完整闭环；下文的时间/力矩/续航指标不能直接作为穿戴配置。

## 1. 产品定位

面向下肢辅助 / 康复训练的**单侧或双侧膝关节外骨骼**。首版 (v0.1) 做单腿，验证驱动与阻抗控制；后续扩展到双腿与步态协同。

## 2. 目标用户

| 场景 | 需求 |
|---|---|
| 负重行走辅助 | 上坡、负重下降时给膝关节助力 |
| 老年人日常辅助 | 蹲下/起立/上下楼梯时主动助力 |
| 下肢康复训练 | 指定角度-速度轨迹训练，记录数据 |

## 3. 核心功能

1. **实时阻抗控制**：100Hz 控制环，电机以 `τ = Kp·Δθ + Kd·Δω + τ_ff` 响应
2. **姿态感知**：IMU 测量大腿姿态、步态相位识别（后续算法）
3. **多模式**：自由模式（零力矩跟随）/ 助力模式（按相位给助力）/ 康复模式（轨迹跟踪）
4. **安全保护**：CAN 看门狗、温度监控、过流保护、急停
5. **数据记录**：通过串口日志或 SD 卡记录关节角度/力矩/IMU 轨迹

## 4. 非功能性需求

| 维度 | 目标 |
|---|---|
| 控制延迟 | 电机反馈 → 指令下发 < 5ms |
| 控制周期 jitter | < ±200μs |
| 单腿重量 (含电机) | ≤ 1.5 kg |
| 续航 | ≥ 1 小时连续辅助行走 |
| 峰值助力 | 17 Nm (RS02 峰值) |
| 启动时间 | ≤ 3s（上电到进入控制循环） |

## 5. 控制策略概述

### 5.1 核心：阻抗控制

电机本身的运控模式 `τ_ref = Kd(v_set - v) + Kp(p_set - p) + τ_ff` 就是 PD + 前馈，天然胜任阻抗：

- `Kp` 大 → 刚性大，外骨骼像"棒"
- `Kp` 小、`Kd` 大 → 柔顺、阻尼
- `Kp = 0, Kd = 0, τ_ff = 任意` → 纯力矩注入（开环力矩）

### 5.2 步态相位助力（未来）

```
站立相 → 伸展助力
摆动相早期 → 屈曲助力
摆动相晚期 → 伸展柔顺
```

用 IMU pitch + 电机 pos 做状态机或基于深度学习的步态识别。

### 5.3 安全

- 看门狗：控制任务阻塞 > 5s → 触发 `rs02_stop(clear_fault=true)`
- 电机温度 > 100°C → 降 Kp，> 120°C → 停机
- 电池电压 < 3.3V/cell → 告警；< 3.0V/cell → 停机
- 硬件急停开关（后续加入）→ 切断电机 + 关闭主控
